# Mini E-commerce Backend API

A simple e-commerce backend API built using Flask.

## Features
- Add products
- View all products
- Update products
- Delete products
- SQLAlchemy ORM
- JSON API responses

## Technologies Used
- Python
- Flask
- Flask-SQLAlchemy
- SQLite3

## Installation

pip install flask flask-sqlalchemy

## Run

python app.py

## API Endpoints

GET /products  
POST /products  
PUT /products/<id>  
DELETE /products/<id>

## Example JSON

{
    "name": "Laptop",
    "price": 50000,
    "stock": 10
}

## Purpose
focuses on backend product management systems.
